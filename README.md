A full-stack web application designed for students to seamlessly discover and register for university workshops, seminars, and club competitions.

## 🛠️ Technology Stack
* **Frontend:** Vanilla HTML5, CSS3, JavaScript (ES6 Client Engines)
* **Backend Framework:** Node.js + Express.js
* **Database Ledger:** SQLite3 Engine
* **Testing Suit:** Automated Node Fetch Injection Engines

## 🚀 Execution & Deployment Instructions

### Prerequisites
Ensure you have [Node.js](https://nodejs.org) installed on your machine.

### Setup and Running Locally
1. **Clone the Shared Repository**
   ```bash
   git clone https://github.com
   cd campus-event-management
   ```

2. **Initialize and Execute Backend Engine**
   ```bash
   cd backend
   npm install
   npm start
   ```
   *The server will automatically generate `database.sqlite` tables and host API endpoints on `http://localhost:5000`.*

3. **Launch the User Interface**
   * Simply navigate into `frontend/public/` and double-click `index.html` to open it inside any modern web browser.
